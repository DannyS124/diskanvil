The window

The list at the top shows every partition. The bottom part shows each disk as a bar, with its partitions drawn to size. Blue means a partition, grey means free (unallocated) space. A lock on a disk means your system is running from it, so DiskAnvil won't change it.

Right-click anything to see what you can do with it. Double-click a mounted drive to open it in your file manager.

How to

Use a USB stick: plug it in, right-click it, Mount, then Open in File Manager. Unmount it before you pull it out.

Format: right-click the partition, Format. Everything on it gets erased.

New partition: right-click grey unallocated space, New Partition. A brand new disk needs a partition table first (right-click the disk on the left, New Partition Table). At the end of an SSD it can leave part of the drive unused, which keeps it fast and makes it last longer.

Resize: right-click the partition, Resize. It can only grow into free space right after it. exFAT can't be resized, XFS can only grow. Back up anything important first.

Rename: select it and press F2.

Delete: right-click, Delete Partition. The space becomes unallocated.

Make a USB stick from an ISO: File → Write Image to USB. Pick the ISO and the stick, type the stick's name to confirm. Compressed images (.xz, .gz, .zip and so on) work as they are. Paste the checksum from the download page if you have it (or pick its SHA256SUMS file with From a File), so a broken download is caught before anything is written.

Copy the files instead: for a Linux ISO, Write Image to USB can also copy its files onto the stick instead of writing the ISO as it is. The stick then stays usable for your own files, and Ubuntu and Debian live sticks can keep changes between starts (persistence). It only starts UEFI PCs, so for an old BIOS-only PC write it as it is.

Windows install stick: File → Make a Windows USB. Pick Microsoft's ISO and the stick. The options are answered for Windows Setup, so it doesn't ask: no TPM 2.0 or Secure Boot needed (for PCs Windows 11 turns down), no Microsoft account, a local account with the name you give it, and so on. Most Windows 11 ISOs need wimlib installed, to split the big install.wim for FAT32.

Is this stick fake? Action → Check a USB Stick. It writes to the whole stick and reads it back (this erases it). Fake sticks say they're bigger than they are and lose what goes past their real size; the check says how much it really holds, and Make It Safe to Use makes a partition that stays inside that. Quick takes minutes, Full checks every byte and takes hours.

A stick or card that won't let you save? Action → Write-Protected Drive (or right-click it). It looks at the stick, the system and its file systems, without changing anything, and says what's stopping it:

  • An SD card's lock switch: slide it up, towards the contacts. A card that's locked in every reader has locked itself.
  • The stick says so itself: its lock switch if it has one; if not, it locked itself to read-only because its memory is wearing out. No program can undo that (the tools that claim to often finish it off), but everything on it can still be copied off.
  • Linux was told not to write to it (a read-only flag): Clear the Flag, with the admin password.
  • DiskAnvil Live's write protection holds it: Allow Writing to It.
  • Open read-only: Linux found errors in its file system and stopped writing. Repair and Open Again. NTFS open read-only usually means Windows didn't shut down fully (Fast Startup): hold Shift while clicking Shut down.
  • On Windows: the setting that write-protects every USB drive (StorageDevicePolicies), the read-only marks diskpart sets on a disk or a volume (each taken off with a button), and an administrator's "deny write access" policy (it says where to change it on your own PC).

Make a DiskAnvil Live USB (a rescue stick): File → Make a DiskAnvil Live USB. Pick the DiskAnvil Live ISO (from the releases page) and the stick, type the stick's name to confirm. The stick can then start any PC, new (UEFI) or old (BIOS), even one whose own system won't start, with DiskAnvil and other repair tools on a small desktop. Secure Boot can stay on, except for the memory test. Every start leaves its logs in the logs folder on the stick; when you plug it back in, Make a DiskAnvil Live USB has an Open Logs button for them. Its boot menu also has "Start this PC's own system" (the PC's own Windows or other system, as if the stick weren't in), "Large text and high contrast", and, under Tools and troubleshooting, a check of every file on the stick (on its own, or before copying it to memory).

Keep changes on the Live stick, and a drive for files: when you make it, tick "Keep my changes between starts" (settings, downloads and programs you add are still there next time) and "A drive for my files" (the rest of the stick as exFAT, which Windows, Macs and Linux all read). Linux ISOs copied into that drive's ISOs folder start from the boot menu, under Other ISOs on this stick, with Secure Boot off. A stick made that way can be updated to a new version without wiping it: tick "Only update DiskAnvil Live".

DiskAnvil Live without a stick: File → Put DiskAnvil Live on This PC. It makes a partition in free space on the PC's own drive (shrink one first with Resize if there's none), copies DiskAnvil Live there and puts it last in the PC's boot menu, so the PC starts as before. Press the boot menu key while it starts to pick it. Update It and Take It Off are in the same window. UEFI PCs only.

Unplug a USB drive: right-click the disk on the left, Safely Remove. Everything gets unmounted and the drive is powered off, so it's safe to pull out.

Check for errors: right-click the partition, Check for Errors. If problems are found, DiskAnvil offers to repair them.

Mount a drive every time the PC starts: right-click the partition and tick Mount at Startup. It will show up under /mnt.

Encrypt a drive: tick "Encrypt with a passphrase" when you format or create a partition. To use it later, right-click it and Unlock, then Mount. Lock it when you're done. The lock drawn on it in the map does the same with one click. A BitLocker drive from Windows unlocks the same way, with its password or its 48-digit recovery key. Only Windows can change a BitLocker password (DiskAnvil for Windows does it).

Open an ISO or disk image: File → Open Disk Image (Ctrl+O). It shows up as a disk you can mount and browse. Close it from the disk's right-click menu.

Is my drive OK? The dot on each disk shows its health: green is fine, orange means it's wearing out (keep backups), red means back it up now. Right-click the disk, Disk Health for details and self-tests. USB sticks don't report health. Hard drives also have a conveyance test, for damage from being moved or shipped. If a drive has SMART switched off, Turn SMART On is there too, and Earlier tests lists the last tests DiskAnvil saw finish.

When a drive is failing or needs a look, a bar at the top of the window says so, with Back Up, Details and Dismiss. Dismissed, it stays away until things get worse. Disk Health lists every reason and explains each number (select one); the bold ones are the ones that count. Connection errors usually mean a bad cable or port, not a bad drive.

Firmware: Disk Health shows the drive's firmware version. With fwupd installed, Check for Updates asks it whether there's a newer one. DiskAnvil doesn't install firmware: use your software center or fwupdmgr update, and back up first.

Btrfs: Disk Health shows how many read, write and checksum errors Btrfs has seen on each Btrfs partition. Scrub Now reads everything back and checks it; tick "Scrub every month" to have it done for you.

Bad sectors: right-click the drive, Scan for Bad Sectors. The scan reads everything and changes nothing. If it finds unreadable sectors, Repair rewrites just those: whatever still reads is kept, the rest was already lost. The drive then reuses each spot or swaps in a spare. The "reallocated" count in Disk Health never goes back down; that's normal. If new bad sectors keep appearing, the drive is wearing out.

While it scans, a map of the drive fills in: green reads fine, orange is slow, red can't be read. Hover over a square to see where it is. Slow spots often turn into bad sectors later, so keep a backup of that drive.

Get files off a dying drive: right-click the drive, Rescue Copy. It copies everything that can still be read into an image file (or onto another drive): the easy parts first, then it goes back for the hard ones. You can stop it and start it again later with the same file; it carries on where it stopped. Do this before running any repairs on a failing drive. Then open the image with File → Open Disk Image and copy your files off. Under "Go easy on the drive" it can pause when the drive gets too hot, rest after a run of read errors, or read slower. When one of a hard drive's heads is dying, its read errors come round again and again at the same spacing (the drive's data takes turns between its heads in bands): once that's seen, the dying head's bands still to come are jumped over and copied last, so the good heads' data comes off first. That's on by default; the box for it is there too.

Which files did the bad spots hit? When a Rescue Copy couldn't read everything, Which Files Were Hit? (next to Start) reads the copy's file systems (FAT, exFAT and NTFS) and lists each file with parts that couldn't be read, and how much of each is missing; everything else came off whole. The list can be saved next to the copy. Deleted FAT files whose pieces are a guess, and files Windows keeps compressed, are marked. ext4 and other file systems can't be listed yet: it says so.

"Target is busy": it won't unmount. Something has a file or folder open on it. The error offers Who's Using It? (also on a mounted partition's right-click menu): the programs with something open there, and what (a terminal sitting in a folder on it counts), plus a disk image on it that's attached or a drive mounted inside it. Close It asks a program to close, so it can save; Stop It stops it at once; Try Again unmounts it. Other users' and the system's programs need the admin password to be seen (Look as Admin). Linux and DiskAnvil Live; the Windows version locks the drive instead, so it doesn't need this.

Copy a whole drive: right-click the drive, Clone Drive, for example to move to a bigger SSD. Empty space isn't copied, and on a bigger drive the last partition can grow into the extra space. Pick "replaces the old drive" if the old one is going away (it's an exact copy), or "keep using both" so the copy gets its own IDs. You can't clone the drive you're running from; start from a live USB for that.

Give a copied drive new IDs: a copy made with Clone (as an exact copy) or dd has the same IDs as the drive it came from. With both plugged in, Linux may use the wrong one and Windows switches one of them off, so a bar at the top says when two drives are copies of each other. Action → Give New IDs, or the button on that bar, gives the copy its own disk, partition and file system IDs; type the drive's name to confirm. Leave "Change them in a Linux on it too" ticked if there's a Linux on the copy, so it still starts (it keeps the old files next to the new ones). The window warns when a Windows on the copy might not start afterwards.

Back up a drive or partition: right-click it, Back Up. It's saved as one compressed .img.zst file with a small .json next to it. Keep both. Empty space packs down to almost nothing. Save it on a different drive.

Put a backup back: right-click the drive or partition, Restore Backup, and pick the .img.zst. The whole backup is checked against its checksum before anything is written, so a damaged file can't half-overwrite your drive.

What's using all the space? Right-click a mounted partition, Disk Usage. Big boxes are big folders; click one to look inside. Folders you can't open (other users', the system's) aren't counted.

Free up space: Tools → Disk Cleanup. It removes old package files, packages you've uninstalled, old system logs, your cache folder and the trash. It shows how much each one frees first. On Btrfs with snapshots, the space only comes back once the old snapshots are gone.

Keep an SSD fast: Tools → Optimize Drives. It tells the SSD which space is free (TRIM). Tick "every week" and you don't have to think about it again. Hard drives don't need it, and Linux doesn't need defragmenting.

Snapshots: Tools → Btrfs Snapshots lists your Btrfs subvolumes and the snapshots snapper took (before and after each pacman update, for example). To go back to one, use snapper or the snapshot entries in your boot menu.

Erase an SSD properly: right-click the drive, Secure Erase. The drive erases itself, including spare areas Wipe Disk can't reach. It doesn't work through most USB adapters, so connect the drive inside the PC. If it says the drive is frozen, click Unplug and Replug: it gets the drive ready, tells you when to pull its power cable and plug it back in, finds it again and checks it. Sleep Now does the same on PCs that wake up fine from sleep. If a PC never notices the drive coming back, turn on Hot Plug for that port in the BIOS setup, or use Wipe Disk, which is enough for a hard drive. Keep the PC on until the erase is done. NVMe drives that have it also offer Sanitize, the newer and more thorough erase, and the sector size the drive should have afterwards (on Linux).

How fast is it? Right-click the disk, Benchmark. Reading doesn't change anything; the optional write test uses a temporary file.

Wipe a whole disk: right-click the disk on the left, Wipe Disk. Every byte is overwritten with zeros. Do this before you sell or give away a drive.

Start a disk over: right-click the disk on the left, New Partition Table. You have to type the disk name to confirm. Pick GPT unless it's for a really old computer.

Stop a wipe: while a wipe or a check runs, a bar at the top shows how far it got, with a Stop button (Stop is on the toolbar too). What's already wiped is gone; to use the drive again, make a new partition table. A drive's own Secure Erase can't be stopped once it starts.

Get deleted files back: Action → Find Lost Files (or right-click the drive). Pick the drive or partition the files were on, or a disk image. On FAT, exFAT and NTFS drives it first lists deleted files with their real names and folders, the Recycle Bin's too, and on NTFS what was deleted recently, newest first. Untick Only deleted files to see the rest as well. Then it looks through the whole drive for pictures, documents, videos, music and archives by what's inside them, so it also works on a drive that was formatted or won't open; those get made-up names. If Windows kept earlier versions of the drive, Look in Them brings back what has changed or gone since. Files Windows kept compressed come back unpacked. Pictures show as thumbnails, and the preview shows PDFs, documents, archives, songs and films. Each file says whether it looks whole. Tick the ones you want and save them to another drive: saving onto the same one could overwrite what you're after. On a drive that's failing, make a Rescue Copy first and look in the copy instead (File → Find Lost Files in a Disk Image, which also opens virtual machines' disks: .vdi, .vmdk, .vhd, .vhdx and .qcow2). SSDs usually erase deleted files within minutes, so those are rarely found there.

Get partitions back: right-click the drive, Recover Partitions. If the main copy of a GPT is damaged, it puts back the copy GPT keeps at the end of the drive. DiskAnvil also remembers each drive's layout, so a deleted partition or a wiped table can be put back the way it was. With nothing to go on, Scan the Drive looks for file systems where partitions used to start. Only the partition table is written, never what's in the partitions, and the table that's there now is remembered first, so you can undo it the same way.

Scan for viruses: Tools → Scan for Viruses. Pick a drive or a folder, then Quick (programs, scripts and documents) or Everything. On Linux it uses ClamAV (the clamav package): the first time it downloads its list of viruses, about 250 MB, and after that only small updates. It also points out files dressed up as something else, like invoice.pdf.exe. On a drive with Windows on it, it lists the odd things that start with Windows and checks the boot files and Secure Boot. Tick what you want gone and Delete Ticked Files, Switch Off Ticked for startup entries (what it changes is backed up first, in a "DiskAnvil backups" folder on that drive), or Put Back Windows' Own boot files. Look Up Online checks odd programs and boot files by their fingerprint, only if you say so; nothing else is sent. To scan a Windows PC, DiskAnvil Live is the best place: Windows isn't running, so nothing on it can hide. No scanner catches everything, so if a PC is badly infected, save your files and reinstall.

Look at the partition table itself: Inspect Partition Table shows the MBR, the GPT and its backup copy the way they are on the drive, whether their checksums are right, and any sector in hex. It only reads.

Partition type and flags: right-click a partition, Partition Type and Flags. The type tells other systems and installers what the partition is for; what's on it doesn't change. Changing an EFI or boot partition's type, or the boot flags, can stop the PC from starting from that drive.

Drive settings: Properties of a SATA drive has Drive settings: how hard it saves power, the write cache and read-ahead, and for a hard drive when it spins down, how loud its seeking is, and Sleep Now. UDisks keeps them and sets them again whenever the drive shows up. In DiskAnvil Live, Properties also says whether a drive has a hidden area (HPA) at its end, and Show the Hidden Area gives that space back for good.

RAID and LVM: software RAID arrays and LVM volume groups show up like drives. A RAID array shows whether it's degraded or rebuilding, and Check RAID Array reads it all and compares the copies. LVM needs the udisks2-lvm2 package; for now you can mount, open and check logical volumes, but not create or resize them.

Not sure where to start? Tools → What Happened? Pick what went wrong (deleted, formatted, won't open, clicking, ransomware, Windows won't start...) and the drive. It says how likely the files are to come back, what not to do, and which tools to use, in order.

Look at a found file before saving it: in Find Lost Files, double-click it. The viewer zooms pictures, pages through PDFs, plays films and songs and shows a document's words. Details shows its dates and a photo's camera and place; Inside shows its parts with any damage marked, and can edit a copy in hex. Repair a Copy fixes what can be fixed (PNG, JPEG, Office, PDF, SQLite, a film without its index). Organise → Find by Words finds text you remember.

Look closer: in the viewer, Enhance makes a picture lighter or darker, lifts the dark parts, stretches the levels, smooths grain, sharpens, and takes blur back out: "Out of focus" for a picture that's soft all over, "Moved" for one with streaks (or press Draw Along a Streak and draw along one, and it measures how far and which way). Hold to Compare shows it as it was found. Save as a New Picture saves a PNG, up to four times as big, that says inside it what was done; the file found is never changed. These bring out what's there: they can't add detail the camera never caught, and they never make any up. A film plays at any speed from a tenth of normal, steps a frame at a time (the , and . keys), and zooms in on a part while it plays (the wheel; drag to move). Enhance works on a film's frames as they play, and Save This Frame keeps the one on the screen. Save a Slowed-Down Copy makes a new MP4 at the speed chosen, with what Enhance is set to. That needs FFmpeg, which comes with DiskAnvil Live and the Windows version; on Linux install it (on Arch: sudo pacman -S ffmpeg). The Flatpak has none of its own and uses the PC's, once it may run the PC's programs (flatpak override --user --talk-name=org.freedesktop.Flatpak io.github.DannyS124.DiskAnvil).

Look Closer at Pictures and Films (Tools menu, and a tile on DiskAnvil Live's home screen): the viewer and all its tools for any picture or film, not only ones Find Lost Files found: from the PC, a drive, a stick, a phone's folder, a camera's card. Drop files or folders on it, or choose them; Previous and Next go through them. It plays what the PC can play (on Linux, Qt's FFmpeg backend: almost any film), and shows camera raw photos, HEIC where the PC has the plugin, TIFF, PSD and the rest. The files are only read; what's made is saved as new ones.

Pick a Spot: press it and draw a box around part of the picture: a face, a number plate, a sign. Just that part is shown, filling the window, and the tools and Save work on it (saved up to four times as big, saying where in the picture it was). Pick again inside it to go closer; Whole Picture goes back. In a film, pause where you want and press Pick a Spot in This Frame: the frame becomes a still picture to pick in, with all the tools, and Back to the Film returns. Making a spot bigger shows what's there more clearly; it can't bring back detail that was never recorded.

The forensic tools: the same kinds police video labs use, all keeping a note in what's saved of every step. Local contrast (CLAHE) brings out detail in the dark and the light parts each on its own. Smooth grain evens out the camera's speckle while edges stay sharp. Deinterlace takes out the comb lines an older camera leaves when things move. Straighten: click the four corners of something seen at an angle (a number plate, a sign, a page), clockwise from its top left, and it's made square-on. Stack Frames, for a spot in a paused film: the frames around it are lined up on it to a fraction of a pixel and put together, so the grain, different in each frame, evens out and what keeps still shows more clearly than in any one frame; Twice the size builds it bigger from what the frames hold between them (shift and add). Steady it, in a film's saved copy, takes out the camera's shake. Enlarging uses Lanczos, the sharpest of the usual ways. Local contrast isn't in a film's saved copy (ffmpeg has nothing like it); a frame saved has it.

More of what forensic labs use (the same kinds as Amped FIVE, the tool police video units use; each step written into what's saved, and nothing made up, as SWGDE and ASTM E2825 ask):

  • Played right first: Video levels to full (CCTV that keeps black at 16 and white at 235 looks washed out); one field of an interlaced frame with its lines doubled; the picture's proper shape (4:3, 16:9, twice as tall or wide); a wide lens's bend taken out (Wide lens bend, or Fit to a Straight Line: click three points along something that should be straight).
  • A JPEG decoded again: the smoothest picture whose stored numbers round to exactly what the file has. The squares of a hard-squeezed JPEG or a thumbnail go, and saved as a JPEG with the same tables it would give the same numbers back. JPEG squares is a quicker smoothing of the same.
  • Blur: out of focus as a lens's disc (the true shape) or soft; taken out step by step (Richardson-Lucy) or in one go (Wiener, best on big blurs: raise its grain allowance if speckle or rings appear).
  • Grain: non-local means (each point from the patches that look like it: the best of the free ways), smoothing that keeps edges, or the middle value.
  • Light: Uneven light (a homomorphic filter: a backlit face in a doorway), Retinex (the dark parts as an eye adjusts to them), local contrast. Show what's blown out marks in red what's pure white and in blue what's pure black: nothing can be brought back there.
  • One channel: only red, green, blue, brightness, Cb, Cr, hue, saturation or value, or the one with the most contrast in this picture. Writing and plates often stand out in one.
  • Frames: Stack Frames puts the frames around a paused one together: the average (the most grain taken out), the middle value or the average without outliers (a passer-by in a few frames is left out), the sharpest only. Once a number plate or sign is straightened, Stack Frames (Following It) follows its four corners from frame to frame, straightens each frame and stacks them: what really helps a plate. It works on flat things; on a face it isn't safe, and the result shouldn't be read as one.

What it can't do: nothing can bring back detail that was never recorded. Stacking cuts grain by about the square root of the frames used and adds at most a little resolution, on things that keep still; de-blurring fails on pictures squeezed very hard; blown-out parts hold nothing. "Enhance" in films is made up; so is "AI" enlarging, which invents detail (a court threw out AI-enhanced video in 2024). DiskAnvil doesn't do it.

Enhance profiles: the list at the top of Enhance sets everything at once. DiskAnvil's own: Too dark, Out of focus, Moved while it was taken, Faded old photo, Night camera, Grainy, Scanned page and Film negative. Set things your way and use Profiles → Save as a Profile to keep them under a name. Profiles → Save This Profile as a File makes a small .anvil-enhance file to give to anyone with DiskAnvil, who drops it on the viewer (or uses Add Profiles From Files) to add it. Only the settings are read from it, each kept to what the tools can do. They're kept in DiskAnvil's own folder (on Linux ~/.local/share/diskanvil/enhance-profiles, on Windows %APPDATA%\diskanvil\enhance-profiles; on DiskAnvil Live they last until it's shut down, unless the stick keeps your changes).

Where was it taken? A photo's or a phone film's details say the town or city it was taken in, worked out without the internet (from GeoNames' list of places), with Open on OpenStreetMap to see the spot (it asks first: that website is told the spot). Organise → Where They Were Taken shows every found photo and film that says where, on a world map and by place. The details also show the camera's serial number, which way it faced, the satellites' time (which says the time zone the camera's clock was on), and signs it was changed after it was taken (an editing program, its own record of changes).

Documents: the details of a Word, Excel, PowerPoint, OpenDocument or PDF file say who wrote it, who changed it last, when it was last printed, how many times it was saved and the time spent editing it. A PDF saved again after it was made keeps each earlier version inside it: right-click it, Earlier Versions Inside It, and each one is listed as a file of its own.

Fingerprints and reports: right-click a found file, Fingerprints, for its MD5, SHA-1 and SHA-256 (the same file always gives the same ones, so they show later that a copy is unchanged). Saving found files also writes a SHA256SUMS file next to them. Organise → Save a Report lists the files with everything known about them, and their fingerprints if you want, as a web page, a spreadsheet (CSV) or a PDF.

Why Did It Crash? (Tools menu, and a tile in DiskAnvil Live): a Windows that keeps blue-screening, freezing or restarting by itself, explained from its own records without starting it (best from DiskAnvil Live). Its event log says when it stopped without shutting down and how: a blue screen and its stop code, the power button held, the power cut or a hard freeze, dying on the way to sleep. Its crash dumps say which driver's code was running, and what that driver is (from the driver file's own details). Disk, file system and hardware errors logged in the half hour before each one are listed with it. At the top, what they have in common: the same driver every time (update or roll it back), different stop codes every time (usually hardware: test the RAM), the disk, the power. A driver is only named with evidence, and it says how it's known. Save Report keeps it as text, for a forum post or a repair shop.

Windows Won't Start (Tools menu, and a tile in DiskAnvil Live): two common reasons a Windows stops starting, fixed from outside it. A stuck update ("Undoing changes", "Preparing Windows" or "Working on updates" for ever): Windows keeps what it has still to do in WinSxS\pending.xml, and points at it from its COMPONENTS registry file. Undoing it sets pending.xml aside and takes those pointers out, as Microsoft's DISM /RevertPendingActions does; the Windows version runs DISM itself. Windows then starts as it was before the update, and Windows Update tries it again later. A damaged registry file ("the registry file is missing or contains errors", 0xc0000098, REGISTRY_ERROR): SYSTEM, SOFTWARE, SAM, SECURITY and DEFAULT are each checked, and a damaged one can be put back from an earlier day, from Windows' own RegBack copies (Windows stopped making them in 2018 unless told to) or from System Restore's shadow copies. That undoes what changed since, so only do it for one that's damaged. Nothing is deleted: whatever is changed is kept next to itself, renamed .before-diskanvil-<date>.

Are My Files Still OK? (Tools menu, and a tile in DiskAnvil Live): photos, videos and papers kept for years can go bad without anyone touching them: a failing drive, a bad copy, "bit rot". The file is still there with the same date, but what's in it changed. Record Fingerprints reads every file in a folder once and keeps a SHA-256 fingerprint of each in the folder itself, as DiskAnvil fingerprints.sha256 (the format sha256sum reads, so sha256sum -c checks it too); a folder that can't be written to has them kept in DiskAnvil's own folder. Check Now later says, worst first, which files are damaged (changed though their date didn't: nobody saved them), can't be read, are missing, were changed by being saved since, or are new. Several damaged at once usually means the drive is failing. Put damaged files back from another copy before recording again.

Burn In a New Drive (Tools menu, and a tile in DiskAnvil Live): what people who keep a lot of data do with every new, "shucked" or second-hand drive before trusting it. The drive's own short self-test; every byte written and read back (Check a USB Stick's full check, so a fake drive that holds less than it says is caught too; tick the box to do it twice, the second time with every bit flipped); its long self-test; then its health counters compared with before. Sectors reallocated, pending or uncorrectable, NVMe media errors or spare space dropping fail it; cable (CRC) errors, command timeouts and running too hot are a warning, since they usually point at the cable, the power or the air. It takes hours, a day or more for a big hard drive, erases the drive (after its name is typed), and ends with a verdict and a PDF report. A drive that doesn't report its health (through some USB adapters) gets the writing and reading only, and the report says so.

Write Speed Over Time (Tools menu, and a tile in DiskAnvil Live): most SSDs, and many USB sticks and SMR hard drives, write into a fast cache first and slow down a lot once it's full, which is why a big copy starts fast and then crawls. This writes a lot at once, straight to the drive (past the computer's own cache) and with data that can't be compressed, and draws the speed as it goes. At the end it says how much went in fast (the cache), the speed before and after, and when the speed after is very low for an SSD, that it's a cheap or fake one. It writes into a test file in the drive's free space, deleted at the end (nothing on the drive is touched), or over a whole empty drive (after its name is typed). Write more than the cache to see the drop: some hold 50 GB or more.

Self-Encrypting Drive (Action menu, and a tile in DiskAnvil Live): many SSDs and some hard drives encrypt everything inside the drive itself (TCG Opal and its cousins) and can be locked with a password. Ask the Drive gets its own answer, read-only: what kind it is, whether it encrypts, whether its locking was switched on and whether it's locked right now, and whether it shows a small stand-in "shadow" disk until it's unlocked. A second-hand drive still locked with a password nobody has (it shows up empty or tiny, or can't be partitioned) can be reset with the 32-character PSID printed on its label: it goes back to how it left the factory, and everything on it is erased for good (its key is replaced). Type the PSID and the drive's name to confirm. It needs administrator rights (DiskAnvil Live's own, or the admin password on a PC), the PSID is passed on privately, and the drive the system runs from is never reset. Some USB adapters don't pass the drive's answer on: plug the drive in directly. Enterprise drives use their maker's tool.

Hardware Check (Tools menu, and a tile in DiskAnvil Live): the parts of a PC people ask a repair shop about, besides its drives. This PC: its processor, memory, board and firmware, and each battery's wear (what it holds when full against what it held new) and charge cycles. Processor: every core worked flat out for 1, 3 or 10 minutes with its temperature drawn; at 95 °C or more, or slowing itself down a lot as it heats, it says the cooling isn't keeping up (dust, a tired fan, dried paste). On Windows many PCs don't give their temperature, and only the speed is watched. Keyboard: each key pressed lights up, so a dead one shows. Screen: the whole screen in black, white, red, green, blue and grey, for stuck or dead pixels and patches. Camera: its picture. Save Report as PDF keeps it all. The memory itself is tested from DiskAnvil Live's start menu.

What This PC Did (Tools menu): what system is on a drive and what it was used for, read from its own records without starting it. On Windows: the version, the PC's name and owner, when it was installed and last shut down, the USB drives plugged in (with their serial numbers and when), programs run (how often and when last), files and folders opened, searches, what was typed into the Run box and Explorer, websites visited and files downloaded (Chrome, Edge, Brave, Vivaldi, Opera, Firefox), networks joined and its accounts. On Linux: which distribution and kernels, its accounts, sign-ins, start-ups and shut-downs, programs installed and removed, recent files and websites. On a Mac: its version and accounts. Nothing on the drive is changed, and each line says where it was read from. Save a Report keeps it as a web page, a spreadsheet or a PDF. It's for your own drives, or ones you're allowed to look at. Websites need sqlite3 (it comes with DiskAnvil Live and the Windows version). In the Windows version it also reads the Windows it's running on, but not Linux drives: Windows can't open them (DiskAnvil Live can); and a browser that's open keeps its history locked, so close it first.

Ransomware: Find Lost Files says when files look locked by ransomware, which family it is, and what can be done: a free decryptor if one exists, Windows' earlier versions of the drive, or the deleted originals.

Is it the drive? Disk Health also shows a Seagate drive's own FARM hours next to SMART's (a history that was wiped shows up), eMMC wear, SMR drives, known firmware bugs, partitions that aren't aligned, the failure rate Backblaze measured for the model (Backblaze Drive Stats), and What's That Noise? for clicks and beeps.

Format a camera's SD card: right-click the card, Format as an SD Card. It uses the SD Association's layout for the card's size, which cameras expect.

Encrypted drives: VeraCrypt volumes unlock with their password (and PIM, keyfiles, hidden or system volume). For LUKS, right-click the partition, Back Up Encryption Header: if the header gets damaged, Put Back Encryption Header makes the drive open again.

A NAS's drives, RAID or Windows dynamic disks: a bar says when they're there; Open Read-Only (or Tools → Open RAID, NAS and Dynamic Disks) opens them without changing anything, so their files can be copied off.

A PC that won't start: from DiskAnvil Live, Tools → Save My Files copies people's folders and bookmarks off. Boot Menu Entries shows and fixes the PC's boot menu; Repair Linux Boot puts GRUB or systemd-boot back; Windows Drivers and Services switches off a driver that stopped Windows starting (with a backup); Windows Product Key shows the key before a reinstall.

Try a repair safely: when Check for Errors finds problems, Try the Repair First runs it on a stand-in, so you can look at the result before the drive itself changes.

Windows update error 0x80070643: on Windows, Tools → Make Room for Windows Recovery does Microsoft's steps (KB5028997) for you.

Does this drive start? Right-click it (or File → Try Starting a Disk Image), Try Starting It. It starts in a virtual machine, read-only; whatever it writes is thrown away.

Proof a drive was erased: after Wipe Disk or Secure Erase, a bar offers the Certificate of Erasure: save it as a PDF, and Check It reads the drive back to show it's blank. Tools → Erasure Certificates lists them.

Evidence: right-click a drive, Make an Evidence Image, saves an E01 file with its checksums and a case report. Start DiskAnvil Live with "Drives write-protected" first, so nothing writes to the drive.

Clonezilla images: right-click a partition, Restore from Clonezilla, and pick the image's folder.

In DiskAnvil Live: Tools → Write-Protect Every Drive makes every drive but the stick read-only (one can be let through to save to). Let Someone Help lets someone you trust on the same network see the screen or use a terminal, with passwords made up each time. Start Other PCs from This One lets PCs on the same network start DiskAnvil Live from this one over a cable.

Change the look: View → Theme. System uses your desktop's colors; there's also Classic, Deadshadow and High Contrast, or Make a Theme for your own. Whatever the theme, red still means danger.

Add-ons: Tools → Add-ons → Get Add-ons lists add-ons you can install, or use Install from File for one you have. They add extra actions, like backing up a drive or opening a terminal in it. They show up in the right-click menu and the Tools menu. Before one runs, DiskAnvil shows exactly what it will run and asks. Ones that use admin power (pkexec, sudo) or run a shell ask every time. Look-only add-ons run in a sandbox where they can't change anything, and they're the only ones offered for the disk your system runs from. An add-on that turns up without being installed through DiskAnvil is marked "Added outside": if you didn't put it there, remove it. Only install add-ons you trust.

To make your own, Tools → Add-ons → Make an Add-on: fill in what it runs, where it shows up and what it asks for, and Test it on the selected drive before you save. An add-on can ask for things in a form, have settings, and show what it prints in a window. In the Add-ons window you can pin an action to the toolbar or give it a shortcut.

Which file system?

  • exFAT: USB sticks and external drives, works on Windows, Mac and Linux (needs exfatprogs)
  • FAT32: old devices and boot sticks, but no files over 4 GB
  • NTFS: drives you also use with Windows
  • ext4: Linux-only drives
  • btrfs: Linux with snapshots, at least 256 MB
  • XFS: Linux, big files, can't shrink (needs xfsprogs)

Problems

Something is greyed out: hover over it in the Action menu to see why.

"Not authorized": the password prompt was cancelled, or there's no polkit agent running. KDE and GNOME have one; on tiling window managers you start one yourself (polkit-kde-agent, polkit-gnome or hyprpolkitagent).

It says something "needs" a package, or isn't installed: install that package (on Arch: sudo pacman -S and its name). DiskAnvil never installs anything by itself.

"Device or resource busy": something still has files open on the drive. Close it and try again.

A drive is missing: press F5. Empty card readers are hidden.

Some of Windows' files can't be opened from Linux or DiskAnvil Live: on small drives (cheap laptops' eMMC especially) Windows keeps its own files compressed (CompactOS), and compact.exe or CompactGUI can do that to any others. Windows reads them as usual; Linux only when its NTFS driver was built to (Arch's is, DiskAnvil Live's and ntfs-3g aren't). DiskAnvil unpacks them itself wherever it needs them: Find Lost Files, Windows Drivers and Services, Scan for Viruses, Save My Files and putting Windows' boot files back. For that it opens the drive read-only, which on a PC can ask for your password. Other programs, the file manager included, still can't open them.

A USB stick still shows two partitions after it held an ISO: a Linux ISO leaves its own layout on the stick, and formatting doesn't clear it. Right-click the stick, Wipe Disk, then New Partition Table and make one new partition.

A Secure Erase got cut off and now the drive is locked: during the erase the drive has the temporary password xxxx. Unlock it with sudo hdparm --user-master u --security-unlock xxxx /dev/sdX, then sudo hdparm --user-master u --security-disable xxxx /dev/sdX (use your drive's name), and run the erase again.

Using the Flatpak? Disk Usage only sees your home folder, /run/media and /mnt. Add-ons, and the tools that run your system's own programs (Seagate FARM through smartctl, Open RAID, NAS and Dynamic Disks, Boot Menu Entries, Put DiskAnvil Live on This PC, the Windows Product Key from the firmware, Btrfs undelete), need one extra permission: flatpak override --user --talk-name=org.freedesktop.Flatpak io.github.DannyS124.DiskAnvil. Try Starting It can't work there: QEMU runs outside the Flatpak and a drive can't be handed to it. The Arch package doesn't have these limits.

Still stuck? Open an issue at github.com/DannyS124/diskanvil/issues and paste the output of diskanvil --dump.

On Windows

DiskAnvil works the same way on Windows, with Windows' names: drives are Disk 0, Disk 1 and so on, and partitions show their letters. It asks for admin rights every time it starts, because Windows only lets admins work with drives directly; that's also why there's no password prompt for each change.

Not on Windows: the Linux things, so LUKS encryption, LVM and RAID, Btrfs snapshots, mount at startup, add-ons, Quick Fixes, the drive settings and the firmware check. Formatting as ext4, Btrfs or XFS, and a drive's own Secure Erase, can't be done from a running Windows: DiskAnvil says so and points you to DiskAnvil Live (or Wipe Disk). Open Disk Image takes .vhd and .vhdx files; Windows opens ISOs by itself.

Only on Windows: Change BitLocker Password (while the drive is unlocked), Optimize Drives with Windows' own weekly task, and Disk Cleanup for Windows' temporary files, the Recycle Bin, error reports and update files shared with other PCs, and Make Room for Windows Recovery (update error 0x80070643). Windows won't format FAT32 over 32 GB, so DiskAnvil does that with its own formatter.

Left to DiskAnvil Live: Write-Protect Every Drive (Windows writes to a drive the moment it's plugged in), Let Someone Help (Windows has Quick Assist for that), Start Other PCs from This One, Repair Linux Boot, the sector size switch, NAS and RAID drives, and VeraCrypt.

Scan for Viruses uses ClamAV if it's installed, and otherwise Microsoft Defender, which keeps its list up to date by itself and always checks every file. The previews in Find Lost Files run without a sandbox there. The Problems above about polkit, pacman and the Flatpak are Linux-only.

Shortcuts

F1 help, F2 rename, F5 refresh, Ctrl+O open disk image, Delete delete partition, Alt+Enter properties, Ctrl+Q quit.
